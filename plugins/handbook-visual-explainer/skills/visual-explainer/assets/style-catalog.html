Commands

Where a style gets spent. Every one of these takes --style and the format flags, so any style composes with any command. The format shown is what the command reaches for on its own — an affinity, not a restriction. Open a section list to see the structure that command emits, taken from its own definition; three of them have no fixed structure and say so. Prefix with handbook-visual-explainer: only if the name collides with another plugin's.

Output formats

A separate axis from style: these set structure, and combine with any style. --handbook --style nord is a document in the Nord palette. The two flags are mutually exclusive — a deck isn't a document.

Page (default)

A scrollable visual page — cards, grids, tables, diagrams. What you get when neither flag is passed.

Deck --slides

One viewport per slide, no scrolling within one. Typography 2–3× larger, bolder compositions. Opt-in only — never chosen for you.

--slides

Document --handbook

Read top to bottom, then returned to: sticky contents rail, numbered chapters, marginalia. Auto-selected for longform docs.

--handbook

Composing

Override a single axis without leaving a style: --palette terracotta+sage, --font fraunces+source-code-pro, --theme dark.

Two values are rejected outright: neon and gradient-mesh. They always produce generic output.
